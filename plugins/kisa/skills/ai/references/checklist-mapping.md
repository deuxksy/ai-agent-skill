## 판정 기준 (실측 대상)

원칙: **실측 사실만 기록 — 미적용 항목은 "조치계획"으로 분류** (진단 스킬이므로 조치는 별도 작업).

| 체크리스트 | 충족 | 조치계획 |
| :--- | :--- | :--- |
| ⑩·④ SA·RBAC | 워크로드별 전용 SA가 최소권한 Role에 실제 연결 | `default` SA 사용·미지정, 권한 객체 부재 |
| ⑧ NetworkPolicy | AI 워크로드 대상 NP 적용 | NP 미적용 (ClusterIP로 직접 노출이 없으면 경계보안은 충족로 병기 가능) |
| ⑨ 통신구간 | AI 서비스 전부 ClusterIP(내부망) + ingress는 TLS | 외부 직접 노출(LoadBalancer·NodePort), TLS 없는 ingress |
| ⑥ 모니터링 | 모니터링 스택(Prometheus 등) 운영 + AI 파드 헬스체크·메트릭 로그 확인 | 스택 부재·로그 미확인 |
| ⑬·① 백업·PVC | PVC Bound + 백업 CronJob 등록 | PVC Bound여도 백업 자동화(CronJob 0건) 미수립 |
| ⑤ 이미지 출처 | 공인 공식 레지스트리(vllm/huggingface 등) 이미지 | 출처 불명 이미지. 공식 이미지라도 사내 레지스트리 미경유면 "부분 충족" 병기 |
| ⑦ API 인증 | 무인증 GET 401/403 | GET 200 (무인증 공개). POST 400은 인증 게이트 통과 후 앱 검증 오류 — 인증 계층 없음으로 판정 |
| ⑫ 스캐너 | 스캐너 어댑터 Running + AI 이미지 스캔 대상 등록·정기 스캔 수립 | 어댑터만 있고 스캔 대상 미등록, 정기 스캔 부재 |

## 실측 주의

- **API 인증은 GET으로 점검** — vLLM 등 일부 서버는 HEAD(`curl -sI`)를 405로 거부한다
- `-n` 플래그는 중복 지정 불가 — 전체 조회는 `-A` 후 grep 필터
- 스캐너 관리 API에 관리자 자격증명이 필요한 경우 파드 상태(`kubectl get pods`)로 대체 판정 — 자격증명을 문서에 평문 기입 금지
- 워크로드 식별 결과(이름·SA·replica·이미지)를 리포트 대상 표로 남긴다 — 증빙 재현성 확보
