# README 및 문서 품질 평가 기준 (README Quality Criteria)

`README.md` 및 프로젝트 문서 체계의 품질을 100점 만점으로 점수화(Scoring)하여 객관적인 진단 결과를 제공합니다.

| 평가 항목 (Criterion) | 배점 (Weight) | 합격 조건 (Pass Condition) |
| :--- | ---: | :--- |
| **1. 프로젝트 요약 (Summary)** | 20 | 100~500자의 사람 중심 프로젝트 목적, 핵심 기능, 해결 과제가 상단 헤더에 명확히 작성됨 |
| **2. Diátaxis 4분면 구조 (Structure)** | 20 | Tutorials, How-To, Reference, Explanation 4개 영역으로 문서가 정확히 분류되고 인덱싱됨 |
| **3. 빠른 시작 및 실행성 (Actionability)** | 20 | 복사-붙여넣기 가능한 Quick Start 명령어가 실제 코드베이스/빌드 환경과 100% 일치함 |
| **4. 링크 및 서브허브 무결성 (Link Integrity)** | 15 | 모든 상대 경로 링크가 깨짐 없이 작동하며 `docs/` 및 `docs/okf/` 서브 허브가 정상 연결됨 |
| **5. 인간 친화적 가독성 (Human-Centric)** | 15 | 사람(개발자/사용자) 중심의 직관적 어조, 가독성 높은 헤더, 목차, 라이선스가 완비됨 |
| **6. 고립 문서 및 중복 관리 (No Orphan)** | 10 | 링크되지 않은 고립 문서(Orphan doc)가 없으며 불필요한 장황함이나 중복 설명이 없음 |

---

## 📊 등급 산정 기준 (Grades)

- **A (90~100점)**: 우수 — 표준 체계를 완벽히 준수하며 즉시 활용 가능
- **B (70~89점)**: 양호 — 구조가 안정적이나 경미한 인덱스/가독성 보완 권장
- **C (50~69점)**: 보완 필요 — 구조적 누락 또는 일부 stale 링크 존재하여 재정비 필요
- **D (30~49점)**: 미흡 — 요약 미비, 링크 오류, 4분면 미비로 대폭 수정 필요
- **F (0~29점)**: 부실 — README가 없거나 내용이 극히 부실하여 새로 작성 필요

## 📋 감사 보고서 출력 표준

1. 스캔한 마크다운 파일 수 및 대상 디렉토리
2. `README.md` 개별 항목별 점수(Score) 및 산출 근거
3. 전체 종합 점수 및 최종 등급 (A~F)
4. 발견된 감점 요인 (깨진 링크, 고립 문서, 불일치 명령어 등)
5. 점수를 개선하기 위한 구체적인 수정 Diff 제안
