# trackers Plugin

일정 동기화, 환율 시각화 추적 및 게임 핫딜/뉴스 알림 스킬을 제공하는 자동화 도메인 플러그인입니다.

## 🛠️ 포함 스킬 (4)

- **`calendar-sync`**: Notion/GCal ➔ Hermes 일정 단방향 읽기 동기화
- **`exchange-rate-tracker`**: 환율 추적 및 시각화 그래프 생성 (USD/KRW, USD/VND)
- **`hot-game-deals-n-news`**: 게임 할인, 무료 게임 및 주요 뉴스 트래커
- **`notion-sprint-sync`**: 로컬 Epic-Story-Task 구조를 Notion 작업 속성에 안전하게 동기화

## 🚀 설치 방법

```bash
claude plugin install trackers@zzizily
```
