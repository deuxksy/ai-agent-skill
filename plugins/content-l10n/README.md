# content-l10n Plugin

이미지 4K 최적화, 기술 문서 한국어 번역 품질 검증 및 딥리서치 제품 기획 파이프라인 스킬을 제공하는 콘텐츠/로컬라이제이션 도메인 플러그인입니다.

## 🛠️ 포함 스킬 (3)

- **`optimize-images-4k`**: ImageMagick 기반 이미지 정리 및 4K Landscape 최적화
- **`korean-translation-verify`**: 기술 문서 한국어 번역 품질 및 가독성 점검
- **`product-planning-dr-pipeline`**: 아이디어를 딥리서치 산출물(AGENTS.md, ROADMAP.md 등)로 발전시키는 기획 파이프라인

## 🚀 설치 방법

```bash
claude plugin install content-l10n@zzizily
```
