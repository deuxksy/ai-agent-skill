# agent-dev-deploy Plugin

AI 에이전트/MCP/LSP 설치 도구, 멀티 에이전트 런타임 교차검증 및 Android WiFi 앱 배포 스킬을 제공하는 개발/배포 도메인 플러그인입니다.

## 🛠️ 포함 스킬 (3)

- **`agents`**: AI 에이전트, MCP 서버, LSP 서버 플랫폼별 자동 설치 및 업그레이드
- **`verify`**: 런타임 중립 교차 검증 (Claude/Codex/agy 러너 + 격리 스냅샷)
- **`deploy-android-wifi`**: WiFi ADB 기반 React Native 앱 자동 빌드 및 배포

## 🚀 설치 방법

```bash
claude plugin install agent-dev-deploy@zzizily
```
